## 📖 Overview

This repository contains the manuscript and figures for a study investigating the clinical and prognostic significance of **CD19 expression in Diffuse Large B-Cell Lymphoma (DLBCL)**.

The project is currently under development and will be progressively updated throughout the manuscript preparation.

---

## 🎯 Objectives

- Investigate CD19 gene expression in DLBCL.
- Evaluate associations with clinicopathological characteristics.
- Assess the prognostic value of CD19.
- Produce publication-quality figures.
- Ensure reproducibility of the study.
